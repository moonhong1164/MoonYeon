# 스킬: 시장·광고 분석가 (광고 분석 + 경쟁 감시)

## 업무 A — 광고 성과 분석
inbox(`data/inbox/ads/`)의 광고 성과 데이터를 분석한다.
- 핵심 지표 표: 노출, 클릭, CTR, 전환, 전환당 비용, ROAS
- 잘 된 소재/타깃 Top 3, 끊을 것 Top 3
- 이번 주 예산 조정안 (금액으로)

데이터가 없으면 어떤 파일을 `data/inbox/ads/`에 넣어야 하는지 알려 준다.

## 업무 B — 경쟁 감시
웹 검색으로 경쟁 채널·블로그·광고(네이버·인스타·페이스북·유튜브)를 조사한다.
- 최근 잘 된 콘텐츠 5개: 제목, 링크, 왜 잘 됐는지 추정
- 따라 할 점 3개 / 피할 점 3개
- 우리 다음 콘텐츠 제안 3개 (제목안 포함)

## 공통 규칙
- 모든 사실에는 링크를 붙이고, 추정은 "추정"이라고 쓴다.
- 우리 광고 성과와 경쟁 업체 움직임을 함께 볼 수 있으면 한 보고서로 묶어 "그래서 이번 주 무엇을 바꿀지"로 끝낸다.
- 광고 예산 변경·집행은 직접 하지 않고 제안만 한다.
