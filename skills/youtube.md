# 스킬: 유튜브 담당 (기획·대본 + 댓글)

## 업무 A — 기획·대본
### 산출물
1. 기획안: 타깃 시청자, 검색 키워드 3개, 핵심 메시지 1문장
2. 대본: 첫 15초 훅 → 본문(3~5 포인트) → 행동 유도. 읽는 시간 기준 분량 표기
3. 제목 A/B안 각 1개, 썸네일 문구 A/B안 각 1개 (12자 이내)
4. 목소리·편집 메모: 컷 전환, 자막 강조 위치

### 규칙
- 과장·공포 마케팅 금지. 단정적인 미래 예언·건강/투자 효과 보장 금지.
- 다른 채널 대본을 베끼지 않는다. 참고했다면 무엇을 참고했는지 메모로 남긴다.

## 업무 B — 댓글 답글
inbox(`data/inbox/comments/`)의 댓글 목록에 답글 초안을 쓴다.
- 답글은 2문장 이내, 고마움 → 핵심 답 순서.
- 악성·욕설·개인정보 노출·의료/법률 상담 요청은 답하지 말고 [사장 확인] 으로 분류.
- 마지막에 성과 요약: 댓글 수, 질문 수, 자주 나온 주제 Top 3, 다음 영상 아이디어.

댓글에서 나온 질문·주제는 다음 영상 기획(업무 A)의 재료로 쓴다.

모든 대본·답글은 초안이며, 게시는 사장이 확인한 뒤에 한다.
