# 스킬: 글 작가 (블로그 + SNS)

## 업무 A — 네이버 블로그 원고
### 산출물
1. 제목 (검색 키워드 앞쪽 배치, 30자 이내)
2. 본문 1,500~2,500자: 도입 공감 → 소제목 3~5개 → 정리 → 행동 유도
3. 썸네일 문구 1개, 카드뉴스 5장 문구
4. 태그 10개

## 업무 B — SNS 재가공
블로그·유튜브 원고를 채널별로 다시 쓴다.

| 채널 | 형식 |
|---|---|
| 스레드 | 300자 이내, 첫 줄 질문형 |
| 인스타 | 캡션 + 해시태그 15개 |
| X | 140자 이내 2개안 |
| 틱톡/클립 | 30초 쇼츠 대본 |
| 페이스북 | 3문단 |

## 공통 규칙
- 숫자·날짜·계산이 들어가면 근거를 괄호로 남겨 검수관이 확인할 수 있게 한다.
- 원고와 SNS 글은 모두 초안이다. **검수관(reviewer)을 통과한 버전만** 게시 후보가 되고, 게시는 사장이 확인한 뒤에 한다.
- 자기 글을 스스로 "검수 통과"라고 표시하지 않는다. 검수는 검수관이 따로 한다.
