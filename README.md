# MoonYeon — 월연 사주 + AI 직원 팀

직원 0명인 1인 사업을 **AI 직원 17명**이 나눠 맡는 운영 시스템과, 그 성과를 보여 주는 **홈페이지**입니다.
사장은 휴대폰(텔레그램)으로 "이거 해줘" 한 줄 보내고, 고객에게 나가는 초안에 **승인**만 누릅니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `config/business.json` | 회사 이름·소개·**회사 규칙**(모든 직원이 지키는 안전 규칙) |
| `config/employees.json` | 부서 5개, 직원 17명, 출근 시간(루틴), 텔레그램 방 6개 |
| `skills/*.md` | 직원별 **업무 지침서(스킬)** — 일하는 방식을 저장해 재사용 |
| `moonyeon/` | 실행 엔진 (Claude API) |
| `site/` | 홈페이지 (정적 HTML, 숫자는 `site/data/stats.json`에서 자동) |
| `data/inbox/<종류>/` | 직원에게 넘길 자료(주문 CSV, 댓글, 문의, 광고, 지출, 메일)를 넣는 곳 |
| `data/outputs/` · `data/outbox/` · `data/worklog.jsonl` | 결과물 · 승인 대기함 · 업무일지 (git 제외) |

### AI 직원 명단

| 부서 | 직원 | 출근 |
|---|---|---|
| ① 콘텐츠·채널 | 유튜브 기획·대본 작가 / 댓글 담당 / 경쟁 채널 감시 / 네이버 블로그 작가 → 블로그 검수관 / SNS 담당 | 평일 9시, 하루 4번, 주 3회, 매일 7시, 매일 13시 |
| ② 판매·고객 응대 | 주문 정리 / 고객 상담 / 광고 분석가 / 상세페이지 기획자 | 매일 0:45, 새벽 2·6시, 월요일 |
| ③ 조사·강의 | 자료 조사원 / 강의 자료 제작자 | 지시할 때 |
| ④ 서류·돈 | 경리 / 서류 담당 / 메일 담당 | 매월 1일, 평일 9·18시 |
| ⑤ 장치 | 비서실장(지시 분배·아침 브리핑) / 업무일지 담당 | 매일 8:30, 23:50 |

`python -m moonyeon team` 으로 언제든 확인할 수 있습니다. 직원을 늘리거나 시간을 바꾸려면 `config/employees.json`과 `skills/`만 고치면 됩니다.

## 안전장치

- 고객·외부로 나가는 직원(`customer_facing`)의 결과는 **승인 대기함**에 들어가고, 사장이 `/approve 번호`를 눌러야 승인됩니다.
- 블로그 원고처럼 `next`가 지정된 일은 **검수관을 통과한 버전만** 승인 대기함에 올라갑니다.
- 텔레그램 봇은 `TELEGRAM_OWNER_ID`(사장 본인)가 보낸 메시지만 받습니다.
- 모든 일(실패 포함)은 업무일지에 남고, 홈페이지 숫자도 여기서 집계됩니다. 숫자를 부풀리지 않습니다.

> 지금은 직원이 **초안·분석·보고**까지 합니다. 승인된 초안을 유튜브/네이버/당근/메일 등에 실제로 올리는 연동은 아직 없으므로, 승인 후 복사해 붙여 넣으면 됩니다. (연동을 붙이려면 `store.decide_outbox` 뒤에 채널별 발송 코드를 추가하세요.)

## 시작하기

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env   # API 키, 텔레그램 토큰/본인 id 입력
```

```bash
set -a && . ./.env && set +a
```

직원 한 명에게 바로 일 시키기:

```bash
python -m moonyeon run researcher "1인 사업자 종합소득세 신고 일정과 준비 서류 정리해 줘"
```

비서실장에게 한 줄 지시 (휴대폰 지시와 동일):

```bash
python -m moonyeon ask "오늘 주문 정리하고 추가 질문 답변 초안까지 써 줘"
```

텔레그램 방 + 매일 루틴 켜기 (24시간 서버에서 실행: `deploy/moonyeon.service` 또는 `Dockerfile`):

```bash
python -m moonyeon bot
```

텔레그램 명령: 한 줄 지시 · `/team` · `/run <직원id> <지시>` · `/outbox` · `/approve <번호>` · `/reject <번호>` · `/log`

## 사주 홈페이지 (`site/`)

**월연 사주** — 20~30대를 위한 사주 사이트입니다. 한지 아이보리·먹빛 초록·금빛 버튼의 이야기형 디자인에, 안내자 캐릭터(달 도령·별 아씨)가 사주를 읽어 주는 콘셉트예요. 캐릭터 그림은 `site/config.js`의 `guides`에 연결하며, 만드는 법은 `docs/marketing/캐릭터-그림-가이드.md`에 있어요.
- **후기**: `site/config.js`의 `reviews`에 허락받은 실제 후기를 넣으면 '월연을 만난 이야기' 영역이 나타나요.

- **무료 사주**: 양력 생년월일·시각을 넣으면 사주 원국표(만세력), 오행 분포, 타고난 성품(일간), 모자란 기운 채우는 법, 올해 기운을 보여 줍니다.
  - 계산은 전부 브라우저 안에서 하며(`site/saju.js`, 외부 라이브러리 없음) 입력 정보를 저장하지 않습니다.
  - 입춘·절기 기준 연주/월주, 23시 자시, 서울 경도 시간 보정(-32분, 끌 수 있음), 1987·1988 서머타임 반영.
  - 음력 생일도 그대로 입력 가능(`site/lunar.js`: 한국 시간 기준 합삭·중기로 계산, 윤달 지원, 1901~2099년).
  - 결과를 카드 이미지로 저장·공유(휴대폰 공유 시트 → 카톡·인스타), 사이트 링크 복사.
- **이달의 운세(무료)**: 무료 사주 결과 맨 위에 이번 달·다음 달 운세(총운·재물·애정·직업·건강·행운·조심할 것·한마디)가 나와요. 그달 월주가 내 일간에게 어떤 십신인지로 풀어요(`site/monthly.js`). 끝에는 잠긴 '평생 사주' 카드로 유료 풀이를 안내해요.
- **상품 상세 페이지**: 상품마다 목차·풀이 미리보기·추천 대상·하단 고정 주문 버튼이 있는 상세 화면이 열려요. `#product=destiny`처럼 주소로 바로 공유할 수 있어요. '운명의 상대'는 생일만 넣으면 배우자 자리·배우자 별·인연이 오는 해를 무료로 맛보기로 보여 줘요(`site/destiny.js`).
- **제휴 상품**: `site/config.js`의 `partners`에 제휴사 트래킹 링크를 넣으면 상품 목록에 '제휴' 카드로 나와요(가격·결제·환불은 제휴사). 클릭은 GoatCounter `partner-○○`로 세고, 코드 기록은 `docs/marketing/제휴-트래킹-코드.md`.
- **재회운세**: 내 생일로 '다시 닿기 쉬운 달'(앞으로 12달), 그 사람 생일까지 넣으면 '두 사람의 결'을 무료 맛보기로 보여 줘요(`site/reunion.js`). 확률 숫자·단정은 쓰지 않아요.
- **유료 풀이**: 재회운세(10장), 운명의 상대(10장), 평생 사주·연애 궁합·재물/직업운·신년운세. 주문서를 작성하면 카카오톡으로 보내고 계좌이체로 결제받습니다.
- **시즌 배너**: `site/config.js`의 `promo`에서 문구·상품·종료일(`until`)을 정하면 첫 화면 위 금색 배너로 보여요. 지금은 2027 신년운세(2027-02-28까지).
- **방문자 분석**: `site/config.js`의 `analytics`에 GoatCounter 코드를 넣으면 방문 수와 무료 사주·주문서 열기·카톡 보내기·공유 클릭 수를 셉니다(개인정보는 보내지 않음).
- **✏️ 사장님이 고칠 곳은 `site/config.js` 하나**: 가게 이름, 카카오톡 채널 주소, 입금 계좌(현재 비움 — 카톡으로 안내), 상품·가격(현재 가격은 예시).

**공개**: `.github/workflows/pages.yml`이 `main`에 `site/` 변경이 올라올 때마다 GitHub Pages로 배포합니다 → https://moonhong1164.github.io/MoonYeon/

## 유료 풀이 만들기

주문이 들어오면:

```bash
python -m moonyeon chart 1995-08-20 07:30 여 김하늘
```

→ 풀이에 필요한 사주 자료(원국·십신·오행·삼합/충·10년 대운·올해/내년 세운)를 뽑아 줍니다. (`node tools/chart.js`와 같음)

```bash
python -m moonyeon reading life 1995-08-20 07:30 여 김하늘 "올해 이직해도 될까요?"
```

→ '사주 풀이 작가' 직원이 `skills/saju-reading.md` 지침대로 초안을 쓰고 승인 대기함에 넣습니다 (Claude API 키 필요). 상품: `life`·`love`·`money`·`newyear`.
API 키 없이도 이 채팅에서 "이 주문 평생 사주 풀이 써 줘"라고 하면 같은 지침으로 써 드립니다. 품질 기준은 `docs/samples/`의 견본 4종(평생 사주·연애 궁합·재물 직업운·2027 신년운세)을 보세요.
