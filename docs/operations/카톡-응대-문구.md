# 월연 카카오톡 응대 문구 세트

카카오톡 채널 관리자센터 → **채팅 → 자주 쓰는 답장(또는 자동응답)**에 아래 문구를 저장해 두고 버튼 하나로 보내세요.
`[ ]` 부분만 그때그때 바꾸면 돼요.

> 계좌번호와 예금주는 홈페이지에 공개하지 않고 여기(카톡)에서만 안내해요. 아래 ②에 사장님 계좌를 넣어 저장하세요.

---

## ① 주문서 받았을 때 (접수 확인)

```
안녕하세요, 월연이에요 🌙
주문서 잘 받았어요!

📮 [상품명] · [금액]원
👤 [이름]님 · [생년월일] [시각]

아래 계좌로 입금해 주시면 확인 후 바로 풀이 작성을 시작할게요.
(입금자명은 주문서 이름과 같게 해 주세요)
```

## ② 계좌 안내 (①과 이어서 보내기)

```
💳 입금 계좌
[은행] [계좌번호]
예금주 [이름]

입금하신 뒤 "입금했어요" 한마디 남겨 주시면 더 빨리 확인할 수 있어요.
```

## ③ 입금 확인했을 때

```
[이름]님, 입금 확인했어요. 감사해요 🙏
지금부터 [이름]님 사주를 차분히 들여다볼게요.

⏰ 풀이는 [날짜] [오전/오후]까지 이 채팅방으로 보내 드려요.
(보통 24~48시간 걸려요)
```

## ④ 풀이 보낼 때

```
[이름]님, 기다려 주셔서 고마워요 🌙
[상품명] 풀이를 보내 드려요.

천천히 편한 시간에 읽어 주세요.
읽다가 궁금한 점이 생기면 언제든 이 채팅방에 남겨 주세요.
([평생 사주는 질문 2개 / 궁합·재물운은 질문 1개]까지 추가로 답해 드려요)
```

※ 풀이가 길면 카톡 글자 수 제한에 걸릴 수 있어요. 그럴 땐 **PDF나 이미지로 만들어 보내거나, 2~3번에 나눠** 보내세요.

## ⑤ 추가 질문에 답할 때

```
좋은 질문이에요!
[이름]님 사주로 보면 [답변 2~4문장]이에요.

더 궁금한 게 있으면 편하게 물어봐 주세요 🌙
```

## ⑥ 풀이 후 후기 부탁 (풀이 보내고 2~3일 뒤)

```
[이름]님, 풀이는 잘 읽으셨나요? 🌙
혹시 괜찮으시면 짧은 후기 한 줄 남겨 주실 수 있을까요?
이름은 가리고, 허락해 주신 내용만 홈페이지·SNS에 소개할게요.
(물론 부담 갖지 않으셔도 괜찮아요!)
```

## ⑦ 시간 밖에 연락 왔을 때 (자동응답)

```
안녕하세요, 월연이에요 🌙
지금은 상담 시간이 아니라 바로 답을 드리지 못해요.
(상담 시간: 평일 오전 10시 ~ 밤 10시)

주문서나 궁금한 점을 남겨 주시면 상담 시간에 가장 먼저 답해 드릴게요!
무료 사주는 홈페이지에서 언제든 볼 수 있어요 👉 https://moonhong1164.github.io/MoonYeon/
```

## ⑧ 처음 말 거는 분께 (상품 안내)

```
안녕하세요, 월연이에요 🌙

📮 월연의 풀이
• 운명의 상대 — [금액]원 (10장)
• 평생 사주 정밀 풀이 — [금액]원 (약 1만 자)
• 연애·궁합 풀이 — [금액]원
• 재물·직업운 풀이 — [금액]원
• 2027 신년운세 — [금액]원 (12달 흐름)

홈페이지에서 주문서를 쓰고 "카카오톡으로 보내기"를 누르시면 가장 빨라요 👉 https://moonhong1164.github.io/MoonYeon/
무료 사주도 거기서 바로 볼 수 있어요!
```

## ⑨ 태어난 시간을 모를 때

```
태어난 시간을 몰라도 괜찮아요!
연·월·일 세 기둥으로 충분히 풀어 드릴 수 있어요.

다만 시간까지 알면 자녀·말년 이야기가 더 정확해져서, 가능하면 집안 어른께 한 번 여쭤봐 주세요.
"새벽", "점심 무렵"처럼 대략적인 것도 도움이 돼요 🙂
```

## ⑩ 환불 문의

```
[이름]님, 말씀 주셔서 감사해요.
아직 풀이 작성을 시작하기 전이라 전액 환불해 드릴게요.
환불받으실 계좌(은행·계좌번호·예금주)를 알려 주세요.
```

풀이를 이미 보낸 뒤라면:

```
[이름]님, 풀이가 마음에 닿지 않았다면 죄송해요.
풀이를 보내 드린 뒤라 환불은 어려워요. 대신 아쉬웠던 부분을 말씀해 주시면,
그 부분을 더 자세히 풀어서 다시 보내 드릴게요.
```

## ⑪ 곤란한 질문 (건강·법률·투자 결정)

```
[이름]님 마음이 많이 쓰이시는 게 느껴져요.
사주로는 흐름과 성향을 말씀드릴 수 있지만, [건강/법률/투자] 같은 결정은 꼭 [의사/변호사/전문가]와 상의해 주세요.
사주로 보이는 흐름은 [간단한 참고 2~3문장] 정도예요.
```

---

## 응대 원칙

- **24시간 안에 첫 답장.** 늦어질 것 같으면 "확인했어요, [시간]까지 답드릴게요"라도 먼저 보내기.
- **약속한 시간 지키기.** 늦어질 땐 미리 알리기.
- **고객 정보는 풀이에만.** 생년월일·연락처를 다른 곳에 옮기거나 공개하지 않기.
- **후기는 허락받은 것만, 이름 가려서.**
