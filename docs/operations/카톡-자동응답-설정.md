# 월연 카카오톡 자동응답 설정

주문을 받는 창구는 두 가지 중 하나로 정해요. 문구는 `카톡-응대-문구.md`의 ①~⑪을 그대로 써요.

| | 카카오톡 채널 | 오픈채팅 |
|---|---|---|
| 만드는 곳 | 카카오톡 채널 관리자센터 (center-pf.kakao.com) | 카카오톡 앱 → 오픈채팅 |
| 자동응답 | **웰컴 메시지 · 키워드 자동응답 · 상담시간 외 응답** 기본 제공 | 1:1 방은 **자동응답 없음** (그룹방은 방장봇 일부 기능) |
| 손님이 보는 이름 | 월연 사주 (공식 채널, 프로필·소개 노출) | 오픈프로필 이름 (개인 계정과 분리됨) |
| 믿음 | 채널 정보·사업자 정보 표시 가능 → 입금 받기에 유리 | 익명이라 "계좌 입금"에 손님이 망설일 수 있음 |
| 추천 용도 | **주문·결제·풀이 발송** | 가볍게 시작하기, 무료 운세 나눔방(커뮤니티) |

> 둘 다 쓴다면: **주문은 채널, 오픈채팅은 소통·이벤트방**으로 나누는 게 가장 깔끔해요.
> 홈페이지 "카카오톡으로 보내기" 버튼은 `site/config.js`의 `kakaoUrl` 하나로 연결돼요. 오픈채팅 주소(`https://open.kakao.com/o/...`)도 그대로 넣을 수 있어요.

---

## A. 카카오톡 채널

관리자센터 → 내 채널 → **채팅**. 먼저 1:1 채팅을 **켜기**로. (메뉴 이름은 업데이트에 따라 조금 다를 수 있어요.)

### A-1. 웰컴 메시지 (처음 들어왔을 때)

```
안녕하세요, 월연이에요 🌙
태어난 날에 담긴 나의 결을 편지처럼 풀어 드려요.

📮 주문은 이렇게
1. 홈페이지에서 주문서를 쓰고
2. 이 채팅방에 주문서를 붙여 넣어 보내 주시면
3. 입금 안내를 바로 드려요

⏰ 상담 시간: 평일 오전 10시 ~ 밤 10시
🔮 무료 사주 보기: https://moonhong1164.github.io/MoonYeon/
```

### A-2. 키워드 자동응답

홈페이지 주문서는 항상 `[월연 사주 주문서]`로 시작해요. **"주문서"** 키워드 하나로 밤에도 접수·계좌 안내가 자동으로 나가요.

| 키워드 | 자동 답장 |
|---|---|
| 주문서 | ① 접수 확인 + ② 계좌 안내 (계좌는 관리자센터에서만 직접 입력) |
| 가격, 얼마, 상품 | ⑧ 상품 안내 |
| 입금했어요, 입금 | 입금 확인되는 대로 바로 알려 드릴게요. 조금만 기다려 주세요 🙏 |
| 시간 몰라요, 시간 모름 | ⑨ 태어난 시간을 모를 때 |
| 환불 | 환불 문의 주셔서 감사해요. 상담 시간에 확인해서 바로 안내해 드릴게요. |

### A-3. 상담 시간 외 응답
상담 시간(평일 10~22시)을 설정하고 그 밖에는 ⑦. 단 **"주문서" 키워드 응답은 시간과 상관없이** 나가게 둬요.

### A-4. 자주 쓰는 답장
③ 입금 확인 · ④ 풀이 발송 · ⑤ 추가 질문 · ⑥ 후기 부탁 · ⑩ 환불 · ⑪ 곤란한 질문

## B. 오픈채팅

### B-1. 방 구성

**① 1:1 주문·상담방** (주문은 반드시 여기서)
- 카카오톡 → 오픈채팅 → 만들기 → **1:1 채팅방**
- **오픈프로필:** 이름 `월연`, 프로필 사진은 홈페이지의 달 엠블럼(月)이나 봉투 그림
- **방 이름:** `월연 사주 · 주문/상담 (평일 10~22시)`
- **방 소개글:**
  ```
  태어난 날에 담긴 나의 결을 편지처럼 풀어 드리는 월연이에요 🌙
  홈페이지에서 주문서를 쓰고 여기에 붙여 넣어 주세요.
  무료 사주: https://moonhong1164.github.io/MoonYeon/
  ```
- **검색 허용:** 켜기 (해시태그: `사주` `신년운세` `재회운세` `궁합` `월연`)

**② (선택) 그룹 소통방** — 무료 운세 나눔·이벤트 공지용
- 방 이름: `월연 · 이달의 운세 나눔방`
- **공지:** 이달의 띠별 한 줄 운세, 새 상품 소식
- **방장봇**(그룹 오픈채팅에서 제공되는 기능, 지원 범위는 앱 버전에 따라 다를 수 있어요)으로 입장 인사와 키워드 응답을 걸 수 있어요.
  - 입장 인사:
    ```
    어서 오세요, 월연의 나눔방이에요 🌙
    공지에서 이달의 운세를 확인해 보세요.
    개인 사주·주문은 1:1방에서 도와드려요 → [1:1방 링크]
    ※ 이 방에 생년월일·연락처를 올리지 말아 주세요.
    ```
  - 키워드 "주문", "가격" → "주문과 가격 안내는 1:1방에서 드려요 → [1:1방 링크]"

### B-2. 1:1방에는 자동응답이 없어요 → 휴대폰 '텍스트 단축키'로 대신해요

문구를 휴대폰 키보드에 저장해 두면, 짧은 단어만 쳐도 긴 문구가 자동으로 바뀌어 들어가요.

| 휴대폰 | 설정 위치 |
|---|---|
| 아이폰 | 설정 → 일반 → 키보드 → **텍스트 대치** → + |
| 갤럭시 (삼성 키보드) | 설정 → 일반 → 삼성 키보드 설정 → 스마트 타이핑 → **텍스트 단축키** → + |

| 단축어 | 바뀌는 문구 |
|---|---|
| `ㅇㅇ접수` | ① 주문서 접수 확인 |
| `ㅇㅇ계좌` | ② 계좌 안내 (계좌번호 포함) |
| `ㅇㅇ입금` | ③ 입금 확인 |
| `ㅇㅇ발송` | ④ 풀이 발송 |
| `ㅇㅇ상품` | ⑧ 상품 안내 |
| `ㅇㅇ시간` | ⑨ 태어난 시간을 모를 때 |
| `ㅇㅇ부재` | ⑦ 시간 외 안내 |

- 텍스트 단축키는 줄바꿈이 들어간 긴 문구가 잘 안 들어갈 수 있어요. 그럴 땐 휴대폰 **메모 앱에 문구를 모아 두고 복사·붙여넣기** 하는 게 가장 확실해요.
- 오픈채팅 1:1방은 손님이 먼저 말을 걸어야 대화가 시작돼요. 답장이 늦지 않게 오픈채팅 알림을 켜 두세요.

### B-3. 오픈채팅에서 꼭 지킬 것
- **그룹방에서는 절대 주문·생년월일을 받지 않기.** 다른 사람이 다 볼 수 있어요. 항상 1:1방으로 안내해요.
- **입금 신뢰 만들기:** 오픈채팅은 익명이라 계좌 입금을 망설이는 손님이 있어요. 사업자등록을 하면 **상호·사업자번호**를 계좌 안내에 함께 적고, 홈페이지 링크를 같이 보내 주세요.
- **사칭 주의 안내:** 공지나 소개글에 "월연은 먼저 입금을 요구하는 연락을 하지 않아요. 주문은 이 방에서만 받아요."를 넣어 두면 사칭 피해를 막을 수 있어요.
- 오픈채팅 운영 정책상 홍보 목적 방은 신고될 수 있으니, 그룹방은 **나눔·소통 위주**로 운영해요.

## C. 홈페이지 연결 바꾸기

오픈채팅 1:1방으로 주문을 받기로 하면 `site/config.js`의 `kakaoUrl`을 오픈채팅 주소로 바꾸면 돼요. 주문서의 "카카오톡으로 보내기" 버튼이 그 방으로 열려요.
