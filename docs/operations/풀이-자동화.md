# 유료 풀이 자동 작성

손님이 홈페이지에서 주문서를 보내면 → 사장님 메일로도 오고 → 입금 확인 후 라벨만 붙이면 → 정해진 시간에 풀이가 자동으로 써져요.

```
홈페이지 주문서 ──(카톡 보내기/복사)──▶ 카톡 + Gmail "[월연 주문] 상품 · 이름"
                                         │
                       사장님: 입금 확인 → Gmail에서 그 메일에 '입금완료' 라벨
                                         │
                 예약 작업(하루 4번) ──▶ 풀이 작성 → 드라이브 '월연 풀이' 폴더
                                         └▶ Gmail 초안 "[검토해 주세요] 이름 · 상품"
                                         └▶ 주문 메일에 '풀이완료' 라벨
                                         │
                       사장님: 읽어 보고 고칠 곳 고친 뒤 카톡으로 발송(④ 문구)
```

## 처음 한 번만 할 일

1. **메일 연결 인증** — 휴대폰으로 `https://moonhong1164.github.io/MoonYeon/mail-setup.html` 열기 → 주문 받을 Gmail 주소 입력 → "인증 메일 보내기".
2. 메일함(스팸함도)에서 **FormSubmit 인증 메일**의 `Activate Form` 누르기.
3. 인증 후 받은 **무작위 주소**(영문·숫자 한 줄)를 `site/config.js`의 `orderMail`에 넣기. 채팅에 "인증했어"라고 하면 대신 찾아 넣어 드려요.
   - 메일 주소를 그대로 넣지 않는 이유: 저장소가 공개라 주소가 노출돼요.

Gmail 라벨(`입금완료`, `풀이완료`)과 드라이브 폴더(`월연 풀이`)는 이미 만들어 두었어요.

## 매번 할 일
- 입금 확인 → 주문 메일에 **입금완료** 라벨 (휴대폰 Gmail: 메일 열기 → ⋮ → 라벨 변경)
- 초안 메일이 오면 드라이브 문서를 읽고 다듬어 카톡으로 발송

## 알아 둘 것
- 풀이는 **손님에게 자동으로 나가지 않아요.** 항상 사장님 검토 후 발송.
- 주문서는 FormSubmit(외부 메일 전달 서비스)을 거쳐 와요. 주문서 아래에 이 안내가 보여요.
- 카톡으로만 주문이 온 경우(메일이 없는 경우)는 채팅에 주문서를 붙여 "풀이 써 줘"라고 하면 돼요.
- 자동 작업 지침: `skills/auto-reading.md`
