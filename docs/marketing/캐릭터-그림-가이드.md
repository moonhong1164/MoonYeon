# 월연 안내자 캐릭터 그림 만들기

홈페이지 첫 화면의 안내자 카드 2장(달 도령·별 아씨)에 들어갈 그림이에요.
그림을 넣기 전까지는 금빛 달 안에 月·星 글자가 보이는 문양으로 채워져 있어요.

## 그림 규격

- **세로형**, 비율 약 **3 : 4.5** (예: 1200 × 1800 픽셀)
- 얼굴과 상반신이 **위쪽 2/3**에 오게 (아래 1/3에는 이름과 버튼이 겹쳐요)
- 배경은 단순하게, 카드 색과 어울리게 (달 도령은 초록 계열, 별 아씨는 남색 계열)
- 파일: JPG 또는 WEBP, 1MB 이하 권장

## 그림 만드는 문구 (ChatGPT 이미지·미드저니 등에 붙여 넣기)

### 달 도령 (月)

```
세로 3:4.5 비율의 한국 웹툰 스타일 일러스트. 20대 중반의 차분하고 다정한 인상의 조선 시대 도령.
길게 늘어뜨린 검은 머리를 반쯤 묶었고, 아이보리 저고리 위에 깊은 초록색 도포를 입었다.
한 손에는 둥근 달 모양의 작은 등불을 들고 있다. 부드러운 미소, 은은한 달빛 조명.
배경은 어두운 초록빛 밤하늘과 흐릿한 한옥 처마, 작은 별 몇 개. 인물은 화면 위쪽 2/3에 상반신으로 배치.
섬세한 선, 부드러운 채색, 고급스러운 분위기. 글자나 로고는 넣지 말 것.
```

### 별 아씨 (星)

```
세로 3:4.5 비율의 한국 웹툰 스타일 일러스트. 20대 중반의 밝고 총명한 인상의 조선 시대 아씨.
단정하게 땋아 올린 검은 머리에 금빛 별 모양 뒤꽂이를 꽂았고, 남색 치마와 연한 금빛 저고리를 입었다.
한 손에 작은 별자리 그림이 그려진 부채를 들고 있다. 살짝 웃는 표정, 별빛 조명.
배경은 깊은 남색 밤하늘과 은하수, 흐릿한 달. 인물은 화면 위쪽 2/3에 상반신으로 배치.
섬세한 선, 부드러운 채색, 고급스러운 분위기. 글자나 로고는 넣지 말 것.
```

## 주의할 점

- **다른 서비스나 작품의 캐릭터를 따라 그리게 하지 마세요.** ("○○ 사이트의 도령처럼" 같은 문구 금지) 월연만의 캐릭터여야 나중에 문제가 없어요.
- 그림 도구마다 상업적 이용 조건이 달라요. 쓰는 도구의 이용 약관에서 **상업적 사용이 가능한지** 확인해 주세요.
- 마음에 드는 그림이 나올 때까지 몇 번 다시 만들어도 괜찮아요. 두 캐릭터의 그림체가 비슷해야 나란히 놓았을 때 예뻐요.

## 그림을 넣는 법

그림 두 장을 이 채팅에 올려 주시면 제가 `site/images/`에 넣고 `site/config.js`의 `guides` → `image`에 연결해 배포해 드려요.
직접 하신다면:

1. `site/images/guide-moon.jpg`, `site/images/guide-star.jpg`로 저장
2. `site/config.js`에서 `image: ""`를 `image: "images/guide-moon.jpg"`처럼 바꾸기

이름·한 줄 소개도 `guides`에서 바꿀 수 있어요.
