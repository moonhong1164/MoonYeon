# 자동 풀이 작성 (예약 작업용 지침)

예약 작업이 정해진 시간마다 이 지침대로 움직여요. **손님에게는 절대 직접 보내지 않아요.** 결과는 사장님 검토용으로만 만들어요.

## 1. 할 일 찾기
- Gmail 검색: `subject:"[월연 주문]" label:입금완료 -label:풀이완료`
- 없으면 "할 일 없음"으로 끝내요. (`[월연 주문] 메일 연결 테스트` 같은 테스트 메일은 건너뛰어요.)
- 한 번에 최대 3건까지만. 남은 건은 다음 회차에 해요.

## 2. 주문 읽기
FormSubmit 메일 본문의 항목을 읽어요: 상품(상품코드), 이름, 성별, 생년월일, 양력음력, 태어난시각, 상대방, 궁금한점, 연락처.
- 상품코드 → `reunion | destiny | life | love | money | newyear`
- 생년월일이 이상하거나(형식이 다르거나 없는 날짜) 성별이 없으면 **풀이를 쓰지 말고** 4번의 "확인 필요" 초안만 만들어요.

## 3. 풀이 쓰기
1. 사주 자료 뽑기:
   ```
   node tools/chart.js --birth <YYYY-MM-DD> --time <HH:MM|모름> --gender <남|여> --name <이름> [--lunar 1] [--leap 1]
   ```
   양력음력이 `음력`이면 `--lunar 1`, `음력 윤달`이면 `--lunar 1 --leap 1`.
   궁합(love)·재회(reunion)는 상대방 생일이 있으면 같은 방법으로 한 번 더 뽑아요(모르면 생략하고 풀이에 그렇게 적기).
2. `skills/saju-reading.md`의 상품별 목차·말투·금지 사항을 그대로 따르고, `docs/samples/`의 해당 견본 수준으로 써요.
   - 길이: 평생 사주 10,000~13,000자 / 운명의 상대·재회운세·신년운세 5,000~7,000자 / 궁합·재물운 4,000~6,000자
   - 차트에 없는 내용을 지어내지 않기. 확률·단정·겁주는 말 금지. 건강·법률·투자는 전문가 상담 안내.
   - 궁금한 점이 있으면 꼭 따로 한 장으로 답하기.
3. 다 쓰면 글자 수를 세서 기준보다 짧으면 보충해요.

## 4. 결과 남기기
- **구글 드라이브**: '월연 풀이' 폴더에 구글 문서로 저장. 제목 `YYYY-MM-DD 이름 · 상품명`.
- **Gmail 초안** (받는 사람: 사장님 본인, 보내지 않고 초안만):
  - 제목 `[검토해 주세요] 이름 · 상품명`
  - 본문: 주문 요약 → 드라이브 문서 링크 → 글자 수 → 사장님이 꼭 볼 곳(절기 경계 출생, 시간 모름, 상대방 생일 모름 등) → 카톡으로 보낼 때 쓸 ④ 발송 문구.
  - 확인 필요 건이면 제목 `[확인 필요] 이름 · 상품명`, 본문에 무엇이 빠졌는지.
- 마지막으로 주문 메일 스레드에 **풀이완료** 라벨을 붙여요. (확인 필요 건도 붙여서 같은 메일을 계속 다시 보지 않게 해요.)

## 5. 개인정보
- 고객 정보는 저장소에 커밋하지 않아요. 작업 중 파일은 `data/outputs/`(git 제외)에만.
- 드라이브 문서를 공유하거나 다른 사람에게 메일 보내지 않아요.
